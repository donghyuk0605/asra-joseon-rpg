# 월영록 — 솔고개 사냥터

조선 다크 판타지 분위기의 클릭 사냥 데모입니다. 바닥을 클릭하면 이동하고, 몬스터를 클릭하면 자동으로 접근해 환도로 공격합니다.

## 실행

```bash
npm install
npm run dev
```

## 조작

- 바닥 클릭: 이동
- 몬스터 클릭: 대상 선택, 추적, 자동 공격
- 전리품 클릭: 자동 접근 후 습득
- `2` 또는 `Space`: 산삼환 사용
- `I` 또는 가방 버튼: 장비·인벤토리 열기

캐릭터 공격은 8방향으로 재생됩니다. 동쪽 계열은 서쪽 계열 원본을 좌우 반전해 동일한 실루엣과 프레임 품질을 유지합니다.

주인공은 무기·복장·부적이 모두 없는 상태로 시작합니다. 무기를 장착하지 않으면 주먹으로 싸우며, 몬스터가 떨어뜨린 장비를 주워 가방에서 장착하거나 해제할 수 있습니다.

캐릭터·몬스터를 추가할 때는 [`docs/SPRITE_MODELING_GUIDE.md`](docs/SPRITE_MODELING_GUIDE.md)의 방향, 크기, 발 기준점, 걷기·공격 프레임 규격을 따릅니다.
