# 무영광산 10종 보스 설계

## 목표

무영광산의 10·20·30층부터 100층까지 각 보스층에 고유 모델과 공격 패턴을 가진 보스 한 종을 배치한다. 보스는 기존 조선 다크 판타지 미술 방향과 스프라이트 규격을 지키며, 공통 전투 엔진 위에서 데이터 기반으로 동작한다.

## 범위

- 10층 단위 보스 10종과 고유 스프라이트 시트 10개
- 보스당 공격 패턴 3종과 체력 50% 기준 2페이즈
- 바닥 경고, 준비 동작, 타격 판정, 회수 동작
- 보스 체력 UI, 페이즈 전환 알림, 카메라·타격 연출
- 보스 생존 중 다음 층 계단 봉인과 처치 후 해제
- 보스층 체크포인트와 재도전

던전 전용 장비, 보물상자, 일반층 클리어 조건은 이번 범위에 포함하지 않는다.

## 보스 명단

| 층 | 보스 | 공격 패턴 |
|---:|---|---|
| 10 | 쇠사슬 광부 망혼 | 쇠사슬 부채꼴 휘두르기, 광석 낙하, 끌어당기기 |
| 20 | 백골 장승귀 | 땅가시, 공포 포효, 장승 분신 |

| 40 | 철갑 산군 | 도약 덮치기, 연속 발톱, 포효 충격파 |
| 50 | 무두 장수 | 장창 돌진, 망령 군기, 회전 베기 |
| 60 | 수몰된 수문장 | 물결 밀치기, 익사자 소환, 침수 구역 |
| 70 | 월식 도깨비왕 | 방망이 지진, 허상 분신, 광폭 연타 |

## 스프라이트 규격

모든 보스는 `docs/SPRITE_MODELING_GUIDE.md`를 따른다.

- 시트 크기: `2048×1280px`
- 셀 크기: `256×256px`, 8열×5행
- 행: 남, 남서, 서, 북서, 북. 동쪽 계열은 런타임 좌우 반전
- 0~3열: 걷기 4프레임
- 4~7열: 대표 공격 4프레임
- 발 기준선: 셀 하단에서 7px 위
- 런타임 원점: `origin(0.5, 0.97)`
- 표시 크기: 일반 몬스터 대비 20~35% 증가, 셀 규격은 변경하지 않음

대표 공격 외 두 패턴은 같은 공격 동작에 고유 이동, 투사체, 소환, 장판 또는 충격파를 결합한다. 정지 이미지 흔들기로 공격을 대체하지 않으며, 모든 실제 피해는 공격 타격 프레임과 동기화한다.

## 아키텍처

### BossCatalog

보스 식별자, 등장 층, 스프라이트 키, 기본 능력치, 이동 속도, 표시 배율, 공격 패턴 3종, 페이즈 규칙을 선언한다. 보스 수치와 패턴 조합은 이 카탈로그에서 변경하고 시뮬레이션 분기문에 흩어 놓지 않는다.

### BossCombatController

보스 전용 상태 기계를 관리한다.

`대기/추적 → 패턴 선택 → 경고 → 준비 → 타격 → 회수 → 재사용 대기`

패턴은 거리, 이전 패턴, 페이즈와 재사용 대기시간을 고려해 선택한다. 같은 패턴이 세 번 연속 선택되지 않도록 한다. 경고가 끝나기 전에는 피해를 주지 않으며, 타격 이후 회수 상태가 끝나기 전에는 이동이나 다음 공격을 시작하지 않는다.

### GameSimulation

보스 위치, 방향, 체력, 충돌, 공격 타이밍과 피해 판정을 관리한다. 렌더링 오브젝트를 참조하지 않는다. 10층 단위에서는 일반 몬스터 6마리를 비활성화하고 해당 층 보스 한 종만 활성화한다.

### HuntingScene

보스 스프라이트, 애니메이션, 바닥 경고, 투사체, 충격파, 소환체, 피격 효과, 카메라 흔들림과 보스 체력 UI를 표시한다. 시뮬레이션 이벤트를 받아 연출하며 피해 여부를 독자적으로 결정하지 않는다.

## 전투 흐름

1. 보스층 진입 시 해당 층을 재도전 체크포인트로 기록하고, 보스를 중앙 전투 구역에 생성한 뒤 다음 층 계단을 봉인한다.
2. 플레이어가 이동하거나 보스를 선택하면 전투가 시작된다.
3. 보스는 패턴 경고 후 지정된 타격 시각에만 피해를 적용한다.
4. 체력이 50% 이하가 되면 진행 중 공격을 취소하고 짧은 무적 전환을 시작한다.
5. 2페이즈에서는 새 패턴 또는 기존 패턴 조합을 열고 경고 시간을 무분별하게 줄이지 않는다.
6. 보스 처치 시 다음 층 계단 봉인을 해제하고 해당 층의 클리어 상태를 기록한다.
7. 100층 보스 처치 시 최종 클리어 이벤트와 전투 기록을 표시한다.

## 사망·재도전·예외 처리

- 보스전 중 플레이어가 사망하면 보스 체력, 페이즈, 소환체, 투사체와 장판을 모두 초기화한다.
- 플레이어는 흑철 폐광고개의 무영광산 입구에서 부활한다.
- 재입장 시 마지막으로 도달한 10층 단위 보스층부터 재도전할 수 있다. 보스 처치 여부와 관계없이 해당 보스층 진입 시점에 체크포인트가 저장된다.
- 보스 에셋 로드에 실패하면 일반 몬스터 텍스처를 보스로 대체하지 않는다. 보스층 진입을 막고 명확한 로드 오류를 기록한다.
- 페이즈 전환 중에는 중복 전환과 피해를 막는다.
- 보스 처치 이벤트는 한 번만 발생하며 계단 해제와 체크포인트 기록도 멱등적으로 처리한다.

## UI와 피드백

- 보스 전용 체력 막대에 이름, 층, 현재 페이즈를 표시한다.
- 위험 패턴은 바닥 도형과 짧은 문구로 미리 알린다.
- 경고 영역과 실제 피해 판정은 같은 패턴 데이터에서 생성한다.
- 페이즈 전환 시 짧은 화면 연출과 보스 이름 표시를 사용하되 HUD와 플레이어 입력을 장시간 가리지 않는다.
- 봉인된 계단은 비활성 색상과 `보스를 처치해야 열린다` 안내를 표시한다.

## 성능 기준

- 보스층에서는 보스 한 종만 활성화하고 사용하지 않는 일반 몬스터 AI를 갱신하지 않는다.
- 영구 파티클을 늘리지 않고 일회성 효과를 종료 후 파괴한다.
- 투사체와 장판의 최대 동시 개수를 패턴별로 제한한다.
- DOM HUD는 기존 80ms 갱신 주기를 유지한다.

## 검증 기준

- 각 보스의 5개 원본 방향과 좌우 반전 3방향이 올바르다.
- 걷기에서 발 교차와 접지가 보이고 보스가 미끄러지지 않는다.
- 대표 공격 애니메이션이 방향에 맞게 끝까지 재생된다.
- 경고 도형과 실제 피해 범위 및 타격 시각이 일치한다.
- 체력 50%에서 페이즈가 정확히 한 번 전환된다.
- 보스 생존 중 다음 층 계단은 동작하지 않고 처치 후 활성화된다.
- 플레이어 사망 후 보스 상태와 위험 오브젝트가 초기화된다.
- 체크포인트 재입장과 100층 최종 클리어가 동작한다.
- `npm test -- --run`과 `npm run build`가 통과한다.
- 브라우저에서 진입, 이동, 보스 공격, 페이즈 전환, 사망, 재도전, 처치와 계단 해제를 확인한다.
