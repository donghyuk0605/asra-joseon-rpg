# 주인공 장비 레이어링 설계

## 문제

현재 런타임은 장비 조합별 완성 캐릭터 시트를 통째로 교체한다. 각 시트가 서로 별도로 모델링되어 머리·골반·발 위치와 보폭이 달라지고, 장비를 장착하면 동일 이동 상태에서도 걷기가 바뀐다.

## 결정

주인공의 월드 이동과 보행 포즈는 맨상체·최소 속바지 상태인 `joseon-hero-base-body-v6.png` 하나만 진실의 원천으로 사용한다. 복장은 이 몸과 한 번에 생성한 착용 원본에서 투명 40프레임 부품 시트로 분리해 같은 프레임 번호, 방향 반전, 원점, 배율을 공유한다. 무기는 인벤토리 아이콘과 분리된 인게임 전용 투명 자산을 40개 방향·액션 프레임별 손 부착점에 붙인다.

기본 렌더 순서는 그림자, 기본 몸, 복장, 무기이며 북·북서 방향의 무기는 몸 뒤로 보낸다. 모든 부품은 동일한 Phaser 컨테이너에 놓는다. 장비 교체는 부품 가시성과 장비 텍스처만 변경하며 기본 몸의 애니메이션 키와 현재 보행 프레임을 바꾸지 않는다.

## 액션

- 걷기: 기본 몸의 0~3열을 재생하고 보이는 장비 레이어를 같은 프레임으로 동기화한다.
- 맨손 공격: 기본 몸의 4~7열을 재생하고 복장 레이어만 동기화한다.
- 무기 공격: 기본 몸과 복장은 4~7열을 같은 프레임으로 재생하고 무기는 각 열의 손 부착점·회전값을 따른다.
- 방향: 몸과 복장은 같은 `directionToFrame()` 및 `flipX`를 쓰고, 무기 부착점은 같은 방향 결과를 좌우 반전한다.
- 피격·사망·히트스톱: 컨테이너나 모든 표시 레이어에 동일하게 적용한다.

## 자산

복장 부품은 생성한 착용 원본에서 얼굴·머리·손·발·기본 몸을 제외한 투명 레이어로 추출한다. 결과는 `2048×1280`, 5행×8열, 발 기준선 하단 7px, 40프레임을 유지한다. 복장 외곽과 무관하게 기본 몸에서 계산한 하나의 배율과 발 기준선을 모든 복장에 적용한다. 무기는 `256×256` 인게임 전용 컷아웃과 공통 손 원점 `(0.5, 0.18)`을 사용한다. 원본 완성 캐릭터 시트는 NPC 호환·참조용으로 남기되 주인공 런타임 이동에는 사용하지 않는다.

## 검증

- 장비 유무와 관계없이 같은 방향·같은 프레임에서 기본 몸의 발 픽셀이 동일하다.
- 장비 교체 중 기본 몸 텍스처는 바뀌지 않는다.
- 빈손에는 검 레이어가 보이지 않고, 복장만 장착했을 때 무기가 보이지 않는다.
- 검만 장착하면 기본 맨상체·속바지 위에 검만 나타난다.
- 전체 테스트, 빌드, 브라우저에서 네 조합의 5개 원본 방향과 좌우 반전 3방향 보행·공격을 확인한다.
