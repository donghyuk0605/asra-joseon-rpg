# 베타 몬스터·공성 파괴 그래픽 개혁

## 목표

- 몬스터와 보스가 이동·공격·사망 상태를 서로 다른 실제 프레임으로 보여 준다.
- 부활한 몬스터와 이전 시체가 한 화면에 중복되는 문제를 없앤다.
- 부산진, 평양성, 경복궁, 남한산성, 강화도 전투에 공성기와 전투 진행형 파괴 상태를 연결한다.
- 배경에 그려진 장식이 아니라 전투 진행도와 함께 바뀌는 런타임 이미지셋으로 운용한다.

## 몬스터·보스 상태

- 활성 몬스터 `61종`은 모두 전용 `2048×1280`, `8×5`, `40프레임` 아틀라스를 쓴다.
- 각 방향의 `0–3열`은 걷기, `4–7열`은 공격이며 발 기준선은 셀 내부 `y=249`다.
- 걷기·돌진·도주·원형 이동은 실제 AI 속도와 방향에 연결된다.
- 공격 피해는 공격 시작 이벤트가 아니라 약 `0.22초` 뒤 충돌 시점에 판정된다.
- 일반 몬스터 시체는 개체 ID를 유지한다. 같은 개체가 부활하면 이전 시체를 즉시 제거한다.
- 던전 보스는 격파 직후 원본 뷰를 숨기고 별도 시체를 `45초` 유지한다. 층 이동 또는 지역 이동 시 정리한다.

## 공성·파괴 이미지셋

런타임 파일: `public/assets/environment/props/siege-destruction-atlas-v1.png`

- 전체: `2048×1024`
- 프레임: `512×512`
- 배열: `4열×2행`, 총 `8프레임`
- 배경: 완전 투명 PNG
- 시점: 동일한 3/4 탑다운, 조선 다크 판타지 재질과 현실적인 목재·철물·기와·석재 비율

| 프레임 | 객체·상태 |
|---:|---|
| 0 | 투석기 준비 |
| 1 | 투석기 발사 |
| 2 | 지붕형 충차 후퇴 |
| 3 | 지붕형 충차 충돌 |
| 4 | 성벽 균열 |
| 5 | 성벽 관통과 돌무더기 |
| 6 | 불타는 목책·구조물 |
| 7 | 붕괴한 기와집 잔해 |

생성 원본은 `assets/sprites/siege-destruction-v1/source/`에 보존한다. 런타임 아틀라스는 `scripts/build_siege_destruction_atlas_v1.py`로 균일 크롭, 투명화, 최대 콘텐츠 영역과 프레임 바닥선을 검사한 뒤 만든다.

## 전투 진행 연결

`siegeDamageStage(defeated, total, cleared)`가 전투 상태를 네 단계로 바꾼다.

| 단계 | 조건 | 화면 상태 |
|---:|---|---|
| 0 | 격파율 34% 미만 | 공성기 동작, 파괴 잔해 없음 |
| 1 | 격파율 34% 이상 | 돌 성벽 균열 |
| 2 | 격파율 67% 이상 | 성벽 균열 유지, 목책·가옥 화재 |
| 3 | 전투 완료 | 공성기 정지, 성벽 관통·가옥 붕괴·목책 잔해 |

대상 전장은 부산진, 평양 외성·대동문·내성, 경복궁 광화문·근정전·내전, 남한산성, 강화도다. 화면 오른쪽 퀘스트·미니맵과 중앙 진군로를 피하도록 각 전장의 성벽 어깨에 배치했다.
