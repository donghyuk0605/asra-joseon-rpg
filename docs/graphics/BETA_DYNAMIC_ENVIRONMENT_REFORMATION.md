# 베타 동적 환경·성곽 조립 그래픽 개혁

## 목표

- 평양·압록 전선·전주 전장의 깃발을 통짜 그림 흔들기에서 `고정 장대 + 4프레임 천` 구조로 교체한다.
- 도형으로 그리던 비와 안개를 실제 8프레임 환경 이미지셋으로 교체한다.
- 북방 설원, 해안 우천, 습지 안개, 강풍 지대가 서로 다른 이동 방향과 밀도로 보이게 한다.
- 모바일·성능 모드·동작 줄이기 설정에서 입자 수와 애니메이션을 낮추되 지역 정체성은 남긴다.
- 성·궁궐은 한 장 배경 위 장식이 아니라 전경 레이어, 가림 영역, 충돌 발자국, 중앙 진군로를 함께 갖는 조립 구조로 유지한다.

## 환경 VFX 이미지셋

런타임 파일: `public/assets/environment/weather/regional-weather-vfx-atlas-v1.png`

- 전체 크기: `1024×512`
- 프레임: `256×256`
- 배열: `4열×2행`, 총 `8프레임`
- 배경: 완전 투명 PNG
- 렌더 방식: 탑다운·3/4 시점 조선 다크 판타지 환경 VFX, 전투 실루엣을 가리지 않는 낮은 밀도

| 프레임 | 환경 상태 |
|---:|---|
| 0–1 | 바람에 흩날리는 눈 |
| 2–3 | 비스듬히 내리는 찬비 |
| 4–5 | 지면을 따라 흐르는 엷은 안개 |
| 6–7 | 마른 잎과 억새 조각을 실은 강풍 |

생성 원본은 `assets/environment/weather-v1/source/regional-weather-vfx-sheet-source-v1.png`에 보존한다. 크로마 제거본은 `assets/environment/weather-v1/processed/regional-weather-vfx-sheet-alpha-v1.png`이며, `scripts/build_regional_weather_atlas_v1.py`가 8개 셀을 같은 안전 영역으로 정규화하고 빈 프레임과 최대 영역을 검사한다.

생성 지침은 다음과 같다.

> 조선 다크 판타지 탑다운 RPG용 4×2 환경 VFX 시트. 한 가지 평면 마젠타 크로마 배경, 셀 경계와 문자는 금지. 1행은 눈 2프레임과 찬비 2프레임, 2행은 지면 안개 2프레임과 바람 잎사귀 2프레임. 각 쌍은 크기·밀도·방향이 이어지고 작은 게임 화면에서도 읽히는 절제된 손그림 질감.

## 지역 연결

- 눈: 평창, 여진 설원부락과 장백–백산–송화–흑송–흑수 전 구간, 압록 전선, 평양 3개 전장
- 비: 오사카 외항, 아와지 해협, 부산진, 강릉, 거제, 보령, 군산, 통영
- 안개: 청람 안개숲, 해주, 야마자키, 대마도 산림, 울릉 해송숲
- 강풍: 완산벌, 탄금대, 양주 봉수로, 울릉 억새초원과 바람고개
- 24개 추가 지방 맵의 안개 수치는 기존 맵 설계값을 유지하면서 동일 아틀라스의 4–5프레임으로 렌더한다.

각 입자는 현재 지역의 월드 좌표를 가지므로 기존 주변 지역 가시성·트윈 정지 시스템에 자동으로 편입된다. 고품질 데스크톱을 기준으로 밀도를 계산하고, 균형·성능·모바일에서 단계적으로 줄인다. 동작 줄이기는 종류당 1–2개의 정지 이미지로 남긴다.

## 깃발 조립

`createWarBanner`는 모든 전투 깃발을 두 부품으로 조립한다.

- 장대: `joseon-flag-pole-ambient-v1`, 위치·각도 고정
- 천: `joseon-flag-cloth-ambient-v1`, 4프레임 순환과 작은 위치·각도 반응
- 적용 전장: 평양 외성·대동문·내성, 압록 국경 전선, 전주 풍남문
- 금지 방식: 통짜 깃발의 `scaleX` 반복, 장대 전체 기울이기, 정지 이미지 흔들기

## 성곽·궁궐 조립 검증

- 부산진성, 경복궁 3구역, 평양성 3구역, 남한산성, 강화도 총 9개 전장은 이름 있는 건축 충돌 발자국을 가진다.
- 경복궁은 10개 전경 레이어, 평양성은 10개 전경 레이어, 부산진성은 5개 배경 크롭 전경으로 분리되어 캐릭터가 건물 앞뒤를 통과할 때 깊이가 바뀐다.
- 성벽·문·전각·민가·망루·목책 충돌은 `campaignStructures.ts`가 단일 기준으로 관리한다.
- 모든 성곽의 중앙 공격로는 플레이어 반지름을 포함해 열려 있으며 테스트가 전 구간을 32픽셀 간격으로 검사한다.
- 브라우저 검증용 캔버스 표식은 `castleAssembly=9:<충돌 수>`, `weatherAtlas=regional-weather-vfx-atlas-v1:8`, `weatherVisual=<지역>:<종류>:<입자 수>` 형식이다.

## 재생성

```bash
python3 scripts/build_regional_weather_atlas_v1.py \
  --input assets/environment/weather-v1/processed/regional-weather-vfx-sheet-alpha-v1.png \
  --out public/assets/environment/weather/regional-weather-vfx-atlas-v1.png
```
